# محطة الأمير — تطبيق مطابقة الورديات

مشروع أندرويد أصلي يعمل دون إنترنت. هذه النسخة هي الأساس التنفيذي للمرحلة الأولى.

## الحسابات التجريبية

- المدير: `0000`
- عامل الديزل: `1111`
- عامل البترول: `2222`
- عامل الغاز: `3333`
- عامل الليل: `4444`

يجب تغيير الأسماء والرموز قبل الاستخدام الرسمي.

## ما يعمل في هذه النسخة

- دخول العامل بالـ PIN.
- 8 طرمبات: 4 ديزل، 3 بترول، و1 غاز.
- توزيع طرمبات النهار، وإظهار جميع الطرمبات لعامل الليل.
- حفظ القراءة السابقة والحالية محليًا.
- حساب المبيعات من فرق العداد × سعر اللتر.
- تسجيل المقبوضات والنقد المسلّم والديون والمخاريج، كل حركة باسم ومبلغ.
- حساب الباقي وإظهار المطابقة أو الفرق.
- إلزام العامل بكتابة سبب عند وجود فرق.
- أرشيف محلي لكل عامل وأرشيف شامل للمدير.
- تجهيز حالات البيانات للمزامنة اللاحقة (`LOCAL`, `PENDING`, `SYNCED`).
- زر فحص تحديث التطبيق، وتنزيل APK وفتح شاشة التثبيت الرسمية.
- شاشة المدير الكاملة: تعديل العمال والرموز، تعديل الطرمبات والأسعار والقراءات، واعتماد الورديات.
- مزامنة الورديات (بعد الإرسال أو الاعتماد) مع Google Sheets عبر Apps Script، تلقائيًا عند فتح الشاشة الرئيسية وعند الإرسال/الاعتماد، وزر يدوي "مزامنة الآن" في لوحة المدير.

## تفعيل مزامنة Google Sheets

1. أنشئ Google Sheet جديد (فارغ يكفي — الشيتات الفرعية تُنشأ تلقائيًا).
2. افتحه، ثم من القائمة: Extensions > Apps Script، والصق محتوى `google-apps-script/Code.gs`.
3. من Project Settings > Script Properties، أضف خاصية باسم `SYNC_SECRET` وقيمتها كلمة سر قوية من اختيارك.
4. Deploy > New deployment > Web app، مع Execute as: Me، وWho has access: Anyone. انسخ رابط `/exec`.
5. في `app/build.gradle`، ضع نفس الرابط في `SYNC_URL` ونفس كلمة السر في `SYNC_SECRET`، ثم أعد بناء التطبيق.
6. بعد أول وردية تُرسل أو تُعتمد، ستظهر تلقائيًا في شيت "الورديات"، مع تفاصيل القراءات والحركات في شيتات منفصلة.

⚠️ لا تضع رابط أو كلمة سر حقيقيين في مستودع عام — اتركهما فارغين في الكود المرفوع، وضعهما فقط في نسخة البناء المحلية أو عبر متغيرات بيئة الإصدار.

## تفعيل التحديث المركزي

1. انشر ملف JSON مطابقًا لـ `update-manifest-example.json` على رابط HTTPS ثابت.
2. ضع الرابط في `UPDATE_MANIFEST_URL` داخل `app/build.gradle` قبل بناء النسخة الرسمية الأولى.
3. كل إصدار جديد يجب أن يحمل `versionCode` أكبر، ويُوقّع بمفتاح التوقيع نفسه.
4. حدّث ملف JSON برابط APK الجديد ورقم نسخته.

التطبيق يفحص التحديث عند فتح لوحة العامل، ويوفر أيضًا زر فحص يدوي. سيطلب أندرويد تأكيد تثبيت APK، وقد يطلب إذن «تثبيت تطبيقات غير معروفة» في المرة الأولى.

- إرجاع الوردية للعامل للتصحيح مع ملاحظة المدير، وظهور الملاحظة في شاشة العامل.
- اقتراح الأسماء تلقائيًا من الأسماء المحفوظة سابقًا عند إدخال الحركات.
- تصدير الأرشيف كملف CSV يفتح مباشرة في Excel، مع إمكانية مشاركته.
- أيقونة تطبيق رسمية.
- تقرير PDF لكل وردية (اضغط على أي بطاقة في الأرشيف) جاهز للطباعة أو المشاركة.
- دعم توقيع الإصدار بمفتاح ثابت، وحقن روابط المزامنة والتحديث وقت البناء بدل كتابتها في الكود.
- إضافة وإيقاف العمال والطرمبات من لوحة المدير (الإيقاف بدل الحذف حفاظًا على الأرشيف).
- حذف حركة خاطئة قبل اعتماد الوردية.
- تخزين رموز الدخول مجزّأة بـ SHA-256 بدل النص الصريح، مع قفل الدخول دقيقة بعد 5 محاولات خاطئة.
- إخفاء رموز التجربة تلقائيًا في نسخة الإصدار.
- Gradle wrapper (`./gradlew`) واختبارات وحدة تعمل في كل بناء.
- نسخة احتياطية واستعادة لكل البيانات من لوحة المدير (ملف واحد يُحفظ في درايف أو يُرسل عبر واتساب).
- تقرير شهري مجمّع لكل عامل: عدد الورديات والمبيعات والفروقات، مع اختيار الشهر.
- مزامنة عكسية: التطبيق يسحب أسعار الوقود المحدّثة من شيت «الأسعار» تلقائيًا.

## توقيع الإصدار الرسمي

1. أنشئ مفتاح التوقيع مرة واحدة واحتفظ به في مكان آمن (فقدانه يمنع تحديث التطبيق لاحقًا):

```
keytool -genkeypair -v -keystore alameer-release.jks -alias alameer \
  -keyalg RSA -keysize 2048 -validity 10000
```

2. **للبناء المحلي:** انسخ `keystore.properties.example` باسم `keystore.properties` واملأ القيم، ثم:

```
gradle :app:assembleRelease
```

3. **للبناء عبر GitHub Actions:** أضف هذه الأسرار في Settings > Secrets and variables > Actions:

| السر | القيمة |
| --- | --- |
| `KEYSTORE_BASE64` | ناتج `base64 -w0 alameer-release.jks` |
| `KEYSTORE_PASSWORD` | كلمة سر الـ keystore |
| `KEY_ALIAS` | `alameer` |
| `KEY_PASSWORD` | كلمة سر المفتاح |
| `SYNC_URL` | رابط Apps Script `/exec` |
| `SYNC_SECRET` | كلمة سر المزامنة |
| `UPDATE_MANIFEST_URL` | رابط ملف التحديث JSON |

عند وجود `KEYSTORE_BASE64` يبني الـ workflow نسخة release موقّعة وجاهزة للتوزيع، وإلا يبني نسخة debug. الأسرار لا تُكتب في المستودع أبدًا، بل تُحقن في `BuildConfig` وقت البناء فقط.

## البناء محليًا

```
./gradlew :app:assembleDebug        # نسخة تجربة
./gradlew :app:testDebugUnitTest    # الاختبارات
./gradlew :app:assembleRelease      # نسخة موقّعة (تحتاج keystore.properties)
```

## تحديث الأسعار من الشيت

أنشئ داخل نفس الـ Google Sheet شيتًا باسم **«الأسعار»** بعمودين:

| نوع الوقود | سعر اللتر |
| --- | --- |
| ديزل | 1200 |
| بترول | 1350 |
| غاز | 900 |

يجب أن يطابق «نوع الوقود» ما هو مكتوب في الطرمبات داخل التطبيق. يسحب التطبيق الأسعار تلقائيًا عند فتح الشاشة الرئيسية، فيصل تعديل السعر لكل أجهزة العمال دون لمسها.

## الخطوات التالية

- رفع أول APK موقّع واستضافته، ثم تعبئة `apkUrl` في `update-manifest.json` ونشره على رابط ثابت.
- تذكير دوري تلقائي بأخذ نسخة احتياطية.
- إخراج التقرير الشهري بصيغة PDF.

## فتح المشروع

افتح مجلد `AlameerStation` في Android Studio أو AndroidIDE، ثم نفّذ Sync وابنِ APK.
