# حركة الصناديق — 2.66.4

أرصدة مستقلة لكل صندوق وعملة (YER / SAR / USD). يمكن إدخالها وتعديلها من الضبط. عند تعديل افتتاحي معتمد يبقى قيده الأصلي، ويضاف قيد للفرق مقابل حقوق الملكية وسطر تدقيق بالقيمة السابقة والجديدة. يحتفظ التعديل بسعر التحويل الأصلي لذلك الافتتاحي. تتطلب الوردية المفتوحة إعادة مطابقة الصناديق والمواد بعد التعديل.

بطاقات مقبوضات، صرف لعميل أو سائق، مخاريج، وتحويل بنفس هيئة بطاقات مطابقة العامل. بطاقة الإضافة تعرض الصندوق والعملة والرصيد الحالي (يشمل الحركات المسجلة في الوردية) والرصيد المتوقع بعد المبلغ الجاري إدخاله. التحويل يعرض أيضًا رصيد الصندوق المستلم وعملته. إضافة الحركة تبقي البطاقة مفتوحة وتحفظ اختيار الصندوق والعملات والنوع، وتفرغ بيانات الحركة التالية. زر إلغاء يغلق البطاقة دون حذف الحركات المسجلة.

ترقية قاعدة البيانات 22 → 23 تحفظ مبالغ القيود السابقة وتحدد عملة الحركات والجرد القديم صراحة. جرد كل عملة مستقل؛ اختيار عملة جديدة لا يحول بقية النقد إليها. أسعار الحركات مثبتة وقت الإدخال. تبقى الحركات للوردية ولا ترحل للدفاتر إلا عند الترحيل النهائي.

التسليم: APK مرشح بالتوقيع ومعرّف الحزمة الخاصين بالتطبيق الأصلي، وتحديث طلب الدمج رقم 5. لا ينشر الفرع إصدارًا عامًا أو تحديثًا تلقائيًا. يقارن البناء توقيع الحزمة بالنسخة المنشورة 2.66.1 كمرجع للتوقيع فقط؛ مصدر التطوير يبقى 2.66.2. نسخة المعاينة السابقة كانت تستخدم توقيع debug غير ثابت، لذلك لا يُوزع ملف debug كتحديث لها. بيانات المعاينة مستقلة عن بيانات التطبيق الأصلي.

التحقق: 118 اختبارًا، بما فيها فصل أرصدة العملات، تعديل الافتتاحي المعتمد بقيد فرق فقط، التراجع الكامل إذا فشل القيد، حفظ أسعار الصرف، ترقية schema 22، الإضافة المتكررة دون إغلاق، وواجهة تعديل الافتتاحي. وردية العامل ذات الحركة المالية الصفرية تعتمد على سجل الترحيل بعد المطابقة ولا تنشئ قيدًا ماليًا بصفر.
