# سجل الفواتير — عداد أصناف البقالة (تطبيق أندرويد منفصل)

تطبيق أندرويد أصلي يعمل على الجهاز، يساعدك على معرفة **كم اشتريت من كل صنف** خلال أي فترة من فواتير الشراء الورقية للبقالة.

## طريقة الاستخدام

1. **التقاط صورة فاتورة** (بالكاميرا) أو اختيارها **من الألبوم**.
2. التطبيق **يحلّل الصورة** ويعرف الأسطر: اسم الصنف + العدد + الوحدة + السعر (مع حذف الإجماليات والتواريخ والأرقام الضارة تلقائيًا).
3. **المراجعة**: عدّل الاسم أو العدد أو الوحدة أو السعر، احذف ما لا ينفع، أو أضف صنفًا يدويًا. أسماء الأصناف السابقة تظهر كإ اقتراحات أثناء الكتابة.
4. **حفظ** الفاتورة بالتاريخ (يُطلب تعديل التاريخ لتسجيل فترة الشراء الفعلية) واسم المحل.
5. من شاشة **«كم اشتريت من كل صنف؟»** اختر الفترة (هذا الشهر / آخر 30 يوم / كل الفترة / تاريخات مخصصة) وشاهد:
   - إجمالي كمية كل صنف خلال الفترة (مع الوحدة الأكثر تكرارًا).
   - إجمالي المبلغ وعدد الفواتير التي ورد فيها.
   - بالضغط على أي صنف: تفصيل كل فاتورة بتاريخها وكميتها.
   - بحث باسم الصنف.
   - **تصدير التقرير CSV** (يفتح في Excel) وإرساله عبر واتساب/Drive.
6. الفواتير المحفوظة: اضغط للتعديل، **اضغط مطولًا للحذف**.

## ملاحظات مهمة

- **أول تحليل** يحتاج إنترنت مرة واحدة لتنزيل نموذج قراءة النصوص (≈15 م.ب) من خدمات Google، وبعد ذلك يعمل دون إنترنت. التطبيق يتطلب وجود **Google Play Services** على الجوال (موجود في أغلب الجوالات).
- إن لم ينجح التحليل (صورة غامضة مثلًا) يمكنك إدخال الأصناف يدويًا — المراجعة اليدوية جزء طبيعي من العملية.
- كل البيانات **محفوظة على الجهاز فقط** (قاعدة بيانات محلية + صورة مصغّرة لكل فاتورة)، لا يوجد أي خادم أو سحابة.
- العملة المعروضة **ج.م** — غيّر النص في `Util` أو الشاشات إن أردت عملة أخرى.

## تثبيت النسخة الجاهزة

1. من GitHub: صفحة Actions → `Build Invoice Counter APK` → آخر run → Artifact `Invoice-Counter-APK` → حمّل `Invoice-Counter-v1.0.0.apk`.
2. انقل الملف للجوال (واتساب نفسه يصلح) وافتحه.
3. سيطلب أندرويد إذن «تثبيت التطبيقات غير المعروفة» لمرة واحدة — اسمح من المتصفح/مدير الملفات.

## بناء التطبيق من الكود

افتح مجلد `invoice-counter` في Android Studio (Hedgehog أو أحدث) ثم Build → Build APK. أو من الطرفية:

```
cd invoice-counter
./gradlew :app:assembleDebug
```

النتيجة في `app/build/outputs/apk/debug/app-debug.apk`.

- Android SDK 35، Gradle 8.9، Java 17، minSdk 26 (Android 8.0+).
- الاعتماد الوحيد: `com.google.android.gms:play-services-mlkit-text-recognition:16.0.1` (تعرّف على النصوص بالعربية).

## بنية الكود

| الملف | الدور |
|---|---|
| `HomeActivity.java` | الشاشة الرئيسية: التقاط/اختيار صورة، قائمة الفواتير المحفوظة |
| `ReviewActivity.java` | شاشة المراجعة: صورة الفاتورة + الأصناف القابلة للتعديل + الحفظ |
| `ReportActivity.java` | التقرير: الفترة + إجمالي كل صنف + تفاصيل الصنف + تصدير CSV |
| `OcrParser.java` | تحويل سطور OCR إلى (اسم/عدد/وحدة/سعر) وقواعد تجاهل الإجماليات |
| `Db.java` | قاعدة بيانات SQLite: الفواتير، الأصناف، الأسماء المقترحة، استعلامات التقرير |
| `AppFileProvider.java` | تزويد الكاميرا بالملفات ومشاركة ملفات التقارير دون مكتبات خارجية |
| `Util.java` | أدوات الواجهة والأرقام والتواريخ |

## تغيير قواعد المحلل

قواعد استخراج العدد والسعر في `OcrParser.parseLine`. مثال شائع: سطر الفاتورة `5 سكر كينج 12.500` → العدد `5`، السعر `12.500`. إن كان شكل فواتيرك مختلفًا (مثلًا السعر قبل العدد) عدّل قواعد `nums` هناك.
